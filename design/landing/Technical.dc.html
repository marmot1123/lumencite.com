開発環境の一部に。

## MCP SERVER

あなたのエージェントに、
ライブラリの読み書きを。

MCP サーバーを内蔵し、Claude Desktop・Claude Code・Codex からライブラリを操作できます（localhost + Bearer トークン、書き込みは既定でオフ）。検索・全文取得・構造の読み取りから、エントリ作成・タグ付け・ノート追記・BibTeX 書き出しまで。Chrome 拡張の Web Clipper でブラウザからのワンクリック取り込みも。

## FEATURES

仕様で語る。

lcir PDF / arXiv TeX を解析し、定理・証明・数式・図表をページ座標つきのツリーに。文中参照は実体ノードに解決。追加時に自動実行 agentic chat FTS5 全文検索 + LCIR 読み取りツールを反復呼び出しして複数文献を横断回答。原文と推論を区別し、引用クリックで PDF の該当箇所へ bibtex sync 変更から 800ms デバウンスで .bib を自動書き出し。cite key はピン留め可・重複自動回避。VSCode LaTeX Workshop を想定 metadata DOI / arXiv ID / ISBN から CrossRef · arXiv · Open Library 経由で自動取得。19 種のエントリタイプ（Zotero 互換） vision ocr テキストレイヤーのないスキャン PDF を LLM ビジョンで転写して索引化。途中停止しても転写済みページは保持 storage ローカルの SQLite。DB + 添付を 1 zip に自動バックアップ（14 世代・検証つき復元）。API キーは OS キーチェーンへ ui ⌘K パレット · KaTeX 数式 · 3 色 PDF ハイライト · 日本語 / English · light / dark / auto · Tauri 2 製ネイティブアプリ
