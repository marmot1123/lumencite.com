ABSTRACT

研究者のためのデスクトップ文献管理アプリケーション。PDF と TeX ソースを解析して論文を定理・証明・数式・図表の構造（LCIR）へ変換し、その構造の上で全文検索と AI との対話を提供する。回答は出典を保持し、原文の記述と推論を区別する。BibTeX の自動同期により LaTeX 執筆環境と接続され、MCP サーバーを通じて外部のエージェントからも操作できる。

Keywords: reference management, LCIR, agentic chat, BibTeX, MCP
01

構造化 — 論文が、読める形になる

追加した論文は自動で解析され、セクション・定理・証明・数式・図表のツリー（LCIR）になります。それぞれのノードは出典のページ座標を保ち、「Theorem 2.3」という文中の参照は、その定理そのものに解決されます。全文検索も、図表の切り出しも、この構造の上に築かれています。

arXiv:quant-ph/0303081 §2 コイン付き量子ウォーク 定義 2.1 定理 2.3 · p.4 証明 式 (14) · 図 3
02

対話 — ライブラリ全体に、問いかける

AI は全文検索と構造の読み取りを繰り返しながら、複数の文献を横断して答えを組み立てます。回答のなかで、論文自身の言葉と LumenCite の推論は区別されます。引用をたどれば、PDF のその場所が開きます。壁打ちの相手は、あなたの本棚です。

標準的な定式化はどれ？ → fulltext_search("coined quantum walk") · 7 hits

導入としては Kempe のレビューが最も整理されています。Kempe 2003 · p.4

03

執筆 — 引用は、書きながら整う

ライブラリの変更は、指定した .bib ファイルへ自動で流れ込みます。cite key は固定でき、重複は自動で回避。エディタを離れずに引用が揃います。CLI と MCP サーバーを備えているので、ターミナルからも、Claude Code のようなエージェントからも、同じライブラリに手が届きます。

\cite{kempe2003} references.bib — 保存のたび自動同期
